# Evidence for Handoffs

Use this reference when deciding what a fresh task must receive and what should remain in durable artifacts.

## Applied principles

1. Make the continuation self-contained around purpose, current state, decisions, evidence, and the next action.
2. Keep progress and discoveries current rather than reconstructing them only at the end.
3. Reference durable sources instead of copying long histories.
4. Preserve unresolved risks and evidence gaps; do not compress them into apparent certainty.

OpenAI's ExecPlan guidance treats long-running plans as living, self-contained documents with current progress, discoveries, decisions, outcomes, exact commands, and recovery information:

- [Codex ExecPlans](https://developers.openai.com/cookbook/articles/codex_exec_plans)

Research on asynchronous handoffs emphasizes externalizing the state needed for another person to reconstruct the work:

- [Knowledge Transfer for Complex Sensemaking Tasks](https://petra.isenberg.cc/publications/papers/Zhao_2018_SHA.pdf)

A handoff is a continuation boundary, not a general archive. Include only information that changes how the next task proceeds.
