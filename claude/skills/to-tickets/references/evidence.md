# Evidence for Ticket Design

Use this reference when selecting task shape, dependency relationships, or tracker-neutral fields.

## Applied principles

1. Preserve outcome, context, acceptance evidence, ownership, blockers, and exclusions across tools.
2. Use vertical slices that can complete and verify independently.
3. Record only genuine blocking relationships; preferred order is not a dependency.
4. Keep the initial unblocked frontier visible for execution or delegation.
5. Adapt to the target tracker only when publication is authorized.
