# Codex Agents and Skills

[English](README.md) · [Українська](README.uk.md) · Русский

Снимок локальной настройки Codex автора на **2026-10-23**, включающий **18 инженерных навыков, 14 специализированных агентов**, общую инструкцию и переносимую конфигурацию.

Навыки охватывают код, безопасность, тестирование, документацию, архитектуру, HTTP API, базы данных, интерфейсы, 3D, наблюдаемость, устойчивость сервисов, зависимости, выпуск ПО и безопасность LLM. Агенты предназначены для исследования, диагностики, реализации, проверки и ревью.

Это личная конфигурация, а не официальный продукт OpenAI. Системные навыки, навыки плагинов, ключи, история чатов, кеши, локальные пути и настройки приложения не публикуются.

## Установка и замена старой версии

Скачайте и распакуйте [ZIP-архив](https://github.com/dayfinggg/openai-codex-agent-skills/archive/refs/heads/main.zip) или клонируйте репозиторий:

```sh
git clone https://github.com/dayfinggg/openai-codex-agent-skills.git
cd openai-codex-agent-skills
```

Из распакованной или клонированной папки запустите установщик. Он использует включенные файлы без повторного скачивания.

### Windows

Требуется Windows PowerShell 5.1 или PowerShell 7.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

### macOS и Linux

Требуется POSIX-совместимая оболочка и утилита SHA-256, например `sha256sum`, `shasum` или `openssl`.

```sh
sh scripts/install.sh
```

Перезапустите Codex после установки.

**По умолчанию выполняется полная замена.** Установщик сохраняет резервную копию, заменяет общую инструкцию, все несистемные навыки и пользовательских агентов, удаляя старый набор. Системные навыки `skills/.system`, плагины, авторизация, чаты и посторонние файлы сохраняются. Значения существующей конфигурации не заменяются, недостающие параметры добавляются, а `model_instructions_file` подключает новую инструкцию.

Для новой конфигурации используются `gpt-6.1-sol` с мышлением `medium` и модель субагентов `gpt-6-luna` с мышлением `max`. **Включены также `approval_policy = "never"` и `sandbox_mode = "danger-full-access"`.** Перед установкой проверьте [конфигурацию](codex/config.toml), если вам не подходят такие права доступа.

## Обновление

Чтобы скачать и установить актуальную версию с GitHub без обновления рабочей копии:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\update.ps1
```

```sh
sh scripts/update.sh
```

Нужен интернет, для оболочки дополнительно нужны `curl` и `tar`. Обновление сохраняет выбранный режим установки. Для Git-клона можно вместо этого выполнить `git pull --ff-only` и повторно запустить установщик.

## Состав

- [Общая инструкция](codex/base_instructions.md)
- [18 навыков с примерами и справочниками](codex/skills)
- [14 агентов](codex/agents)
- [Переносимая конфигурация](codex/config.toml)
- [Режимы установки, резервные копии и другие пути](docs/installation.md)

Инструкции, навыки и агенты перенесены из локальной настройки без переписывания содержимого. Из конфигурации экспортированы только переносимые параметры. Старые навыки, импортированные инструменты skill-creator и устаревшие исследовательские документы удалены.

Параметр `model_instructions_file` заменяет встроенные инструкции модели, а не просто добавляет правила проекта. См. [официальную документацию OpenAI](https://learn.chatgpt.com/docs/config-file/config-reference) и [описание пользовательских агентов](https://learn.chatgpt.com/docs/agent-configuration/subagents). Установщик сохраняет используемую автором структуру `$CODEX_HOME/skills`, хотя [актуальная документация навыков](https://learn.chatgpt.com/docs/build-skills) описывает `$HOME/.agents/skills` для пользовательского набора.

## Проверка установщиков

Требуется Python 3.11 или новее:

```sh
python -m unittest discover -s tests -v
```

Тесты работают во временных папках и не затрагивают настоящую настройку Codex. Отсутствующие оболочки отмечаются как пропущенные проверки.

Сообщения об ошибках принимаются в [GitHub issues](https://github.com/dayfinggg/openai-codex-agent-skills/issues). Лицензия инструкций и программ репозитория — [MIT](LICENSE).
