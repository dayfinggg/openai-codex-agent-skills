---
name: model-domain
description: Map an unfamiliar codebase, architecture, domain, or data flow before substantial changes.
---

Use this skill when the relevant architecture, domain terminology, ownership, or data flow is not already clear.

Read applicable repository guidance and the nearest source of truth. Trace the request from entry point through important boundaries, configuration, persistence, integrations, and tests. Identify invariants, existing extension points, and affected callers before editing. Prefer a small evidence-based map over a broad tour. Record the map only when the task requests documentation or another artifact.
