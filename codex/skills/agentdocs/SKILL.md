description: Write or revise agent instructions, skill descriptions, and linked rule files.
---

Give each rule one owner. Keep session-wide preferences in the always-loaded instructions and task-specific procedures in skills.
Describe the outcome, constraints, and check for completion. Prescribe steps only when their order matters.
Keep a skill description short and specific enough to distinguish it from nearby skills.
Use SKILL.md as a router when branches need different references. Put each reference beside its trigger.
Remove restated defaults, stale version catalogs, repeated examples, and blanket reading requirements.
Prefer concrete positive instructions. Name a prohibited pattern when it addresses a demonstrated recurring failure.
Test revised instructions on a realistic request. Judge behavior, not whether the model repeats the rules.
For Claude Code skill packaging, read [SKILL-MECHANICS.md](references/SKILL-MECHANICS.md). For Codex, use the installed skill-creator guidance and current OpenAI skill documentation.
