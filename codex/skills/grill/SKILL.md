---
name: grill
description: Interview the user to challenge a plan or design when they explicitly request it.
---

Map decisions and their dependencies. Look up facts yourself.
Ask only questions whose prerequisites are settled. Include a recommendation and its main tradeoff.
Keep each round small enough for the user to answer together, then wait for those answers.
Use answers to expose the next unresolved decisions. Distinguish a user decision from an assumption.
Finish when the goal, constraints, risks, and acceptance criteria are settled. Implementation requires authorization.
