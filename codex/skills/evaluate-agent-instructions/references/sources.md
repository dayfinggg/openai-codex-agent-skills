# Sources

Reviewed 2026-08-11.

- [OpenAI, Model guidance for GPT-5.6](https://developers.openai.com/api/docs/guides/latest-model) — lean prompts, isolated changes, representative evals, and workload-specific configuration.
- [OpenAI, Working with evals](https://developers.openai.com/api/docs/guides/evals) — datasets, graders, comparisons, and error analysis.
- [OpenAI, Build skills](https://developers.openai.com/codex/skills) — progressive disclosure, metadata routing, focused workflows, and trigger tests.
- [OpenAI, Custom instructions with AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md) — instruction scope and hierarchy.
- [OpenAI, Subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents) — custom-agent roles, model selection, orchestration, and configuration.
- [Orlanski et al., SlopCodeBench](https://arxiv.org/abs/2603.24755) — longitudinal code erosion and prompt-only mitigation limits.
- [Zhao et al., SpecBench](https://arxiv.org/abs/2605.21384) — reward hacking and hidden composed evaluations.
- [Thillen et al., CodeTaste](https://arxiv.org/abs/2603.04177) — refactoring quality and controlled propose-then-implement comparisons.
- [Spracklen et al., We Have a Package for You!](https://arxiv.org/abs/2406.10279) — package hallucination as a security and correctness failure.
- [Google, Small CLs](https://google.github.io/eng-practices/review/developer/small-cls.html) — focused and independently reviewable changes.
