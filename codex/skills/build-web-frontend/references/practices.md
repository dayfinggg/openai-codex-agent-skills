# Frontend Practices

Accessibility is part of behavior. Start with native semantics, ensure all functionality is available from a keyboard, manage focus intentionally, expose programmatic names and errors, and verify reflow, contrast, zoom, and motion preferences. ARIA supplements semantics when native HTML cannot express the interaction.

Measure user-facing performance with current Core Web Vitals and representative navigation. Avoid optimizing bundle size or rendering patterns without evidence that the change improves the target experience.
