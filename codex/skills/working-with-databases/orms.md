# ORMs

## Prisma 7 and later

- Generator `prisma-client` with an explicit `output` path. `prisma-client-js` is deprecated.
- A driver adapter such as `@prisma/adapter-pg` is required.
- Connection URLs live in `prisma.config.ts`, not in `datasource` blocks of the schema. Environment variables are not loaded automatically.
- Use Client Extensions instead of the removed `$use()` middleware.
- Avoid N+1 with `include` or `relationLoadStrategy: "join"`.

## Drizzle

Check the installed version first, because version 1 changes the relational query API. In version 1 define relations with `defineRelations()`. Generate migrations with `drizzle-kit generate` and review them before applying.

## SQLAlchemy 2

- Models: `class Base(DeclarativeBase)` and columns as `id: Mapped[int] = mapped_column(primary_key=True)`.
- Queries: `session.scalars(select(User).where(User.email == email))`, `session.execute(...)` for rows.
- Eager loading with `selectinload()` or `joinedload()`.
- Migrations with Alembic, always reviewing autogenerated scripts.

Do not write `session.query()`, `declarative_base()`, untyped `Column()` attributes or `engine.execute()`.

## Eloquent

- Casts in a `casts(): array` method, accessors with `Attribute::make()`.
- Call `Model::preventLazyLoading(! $this->app->isProduction())` in `AppServiceProvider::boot` so N+1 fails in development.
- Eager load with `with()`, count with `withCount()`, and process large tables with `chunkById()` or `lazyById()`.
- Mass assignment only through `$request->validated()` and `$fillable`.

## Doctrine ORM 3

Mapping with PHP attributes on entities. Query with the QueryBuilder or DQL with bound parameters. Schema changes through Doctrine Migrations, reviewed before running.
