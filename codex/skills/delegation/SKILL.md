---
name: delegation
description: Choose and brief subagents when delegation is requested or permitted by the active runtime.
---

Delegate only when an independent task benefits from separate context or parallel work. Keep small tasks and tightly coupled work local.
Use the runtime's provider, model, isolation, and waiting rules. Preserve user-specified settings and report unavailable choices without substituting.
For an unconstrained choice, match model capability to task ambiguity and consequence. Use only models and settings exposed by the runtime.
Give each child the goal, relevant evidence, owned paths, constraints, completion check, and stop conditions.
Include the absolute path to ../../base_instructions.md and the skills needed for the task.
Use a fresh context for independent review. Use inherited context when the task depends on this conversation.
Separate writers by file ownership or runtime-managed worktrees.
Inspect returned evidence and the combined diff before accepting completion. Cancel work no longer needed.
