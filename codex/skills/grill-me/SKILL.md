---
name: grill-me
description: Resolve a high-impact product, contract, data, security, compatibility, resource, or architecture decision that evidence cannot settle.
---

Use this skill only when proceeding would commit to a consequential choice about public behavior, data semantics, security or privacy, compatibility, resource limits, or architecture and repository evidence cannot determine the intended answer. Do not use it for ordinary ambiguity, routine fixes, explanations, reviews, or reversible implementation details.

Inspect repository guidance, source, tests, configuration, and authoritative documentation first. Separate facts the agent can establish from decisions only the user can make. Start from one concrete hypothesis about the intended outcome.

Ask one focused question at a time. Use the host's structured question tool when available, with two or three mutually exclusive choices when the decision is bounded. Explain only the consequence that distinguishes the choices. Wait for the answer before asking a dependent question. Do not turn the interview into a questionnaire or explore hypothetical branches that do not affect the requested scope.

Do not edit files or make external changes while a material decision is unresolved. Stop the interview as soon as the remaining path is determined.

Read [references/examples.md](references/examples.md) when the trigger or first question is unclear.
