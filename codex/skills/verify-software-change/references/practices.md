# Verification Practices

Review behavior, design, complexity, tests, naming, comments, style, documentation, and every relevant line. A passing check proves only the property it exercises in that environment. Match verification depth to blast radius and failure cost.

Fresh evidence should include exact commands and current results. Do not infer that checks passed from old logs, compilation, another environment, or the absence of reported failures.
