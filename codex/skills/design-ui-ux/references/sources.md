# Sources

Reviewed 2026-08-01. Prefer the current version of each source when guidance changes.

- [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) — platform hierarchy, harmony, consistency, components, inputs, and accessibility.
- [Apple HIG: Layout](https://developer.apple.com/design/human-interface-guidelines/layout) — adaptable layouts, safe areas, Dynamic Type, localization, RTL, and device variation.
- [Apple Machine Learning Research: Improving User Interface Generation Models from Designer Feedback](https://machinelearning.apple.com/research/designer-feedback) — evidence that structured designer critique and direct manipulation improve LLM-generated UI beyond simple preference rankings.
- [Figma: Design system 102](https://www.figma.com/blog/design-systems-102-how-to-build-your-design-system/) — actionable principles, accessible foundations, tokens, reusable components, and shared language.
- [Figma: Add guidelines to Figma Make](https://help.figma.com/hc/en-us/articles/33665861260823-Add-guidelines-to-Figma-Make) — concise, high-priority LLM guidance and design-system context instead of excessive instructions.
- [Figma: Design systems and AI](https://www.figma.com/blog/design-systems-ai-mcp/) — design-system context, tokens, annotations, and component reuse as controls against generic AI output.
- [W3C: Web Content Accessibility Guidelines 2.2](https://www.w3.org/TR/WCAG22/) — normative accessibility success criteria.
- [W3C: ARIA Authoring Practices Guide](https://www.w3.org/WAI/ARIA/apg/) — accessible interaction and keyboard patterns for composite widgets.
- [Material Design 3: Foundations](https://m3.material.io/foundations) — adaptive, systematic color, typography, layout, motion, and interaction foundations.
- [Microsoft Fluent 2: Design principles](https://fluent2.microsoft.design/design-principles) — platform-native familiarity, adaptability, and reuse of native patterns.
- [IBM Carbon: Accessibility](https://carbondesignsystem.com/guidelines/accessibility/developers/) — semantic structure, predictable keyboard order, native elements, clear language, and restrained customization.
- [Shopify Polaris: Accessibility](https://polaris-react.shopify.com/foundations/accessibility) — inclusive foundations and accessible component reuse in product interfaces.
- [Atlassian Design System: Spacing](https://design-system-docs-proxy.services.atlassian.com/foundations/spacing) and [Atlassian accessibility](https://www.atlassian.com/accessibility) — consistent scales, responsive density, accessible tokens, components, and annotations.
- [Adobe Spectrum: Principles](https://spectrum.adobe.com/page/principles/) — accessibility, honesty, respect for attention, contribution, and coherent cross-product design.
- [GOV.UK Government Design Principles](https://www.gov.uk/guidance/government-design-principles) — start with user needs, do less, use data, simplify, iterate, include everyone, and be consistent rather than uniform.
- [Vercel Web Interface Guidelines](https://vercel.com/design/guidelines) — current implementation-level checks for interaction, forms, focus, animation, performance, typography, and visual polish.
- [Anthropic Claude Code: frontend-design skill](https://github.com/anthropics/claude-code/blob/main/plugins/frontend-design/skills/frontend-design/SKILL.md) — explicit art direction and intentionality as a counterweight to generic AI-generated interfaces.
- [OpenAI: frontend-skill](https://github.com/openai/skills/blob/main/skills/.curated/frontend-skill/SKILL.md) — restrained composition, image-led hierarchy, utility copy for product UI, and purposeful motion.
- [Cursor: Design Mode](https://cursor.com/blog/design-mode) — spatial references, element selection, annotations, and rendered-context feedback for agent-driven UI iteration.
- [Linear: A calmer interface for a product in motion](https://linear.app/now/behind-the-latest-design-refresh) — quiet hierarchy, reduced visual noise, design tokens, feature-flagged comparison, and agents used for exploration rather than taste replacement.
