# Make actions understandable

- Make possible actions discoverable through visible signifiers, familiar controls, clear labels, and consistent placement.
- Match control layout and movement to the effect they produce. Natural mapping reduces explanation and memory load.
- Provide immediate feedback that confirms the input, current state, progress, result, and available recovery.
- Keep the system's conceptual model consistent across labels, navigation, states, and workflows so users can predict what happens next.
- Put necessary knowledge in the interface when recognition is safer than recall. Do not require users to memorize hidden modes, codes, or earlier values.
- Use constraints to prevent impossible actions and to narrow choices without trapping the user.
- Distinguish disabled, unavailable, loading, selected, saved, failed, and completed states visibly and accessibly.
- Treat repeated user error as a design signal. Improve constraints, defaults, mapping, feedback, or recovery before blaming the user.
