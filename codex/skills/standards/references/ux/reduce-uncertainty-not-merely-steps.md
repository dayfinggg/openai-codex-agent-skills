# Reduce uncertainty, not merely steps

- Optimize for clear decisions and continued confidence rather than an arbitrary click or screen count.
- Give navigation choices a strong information scent with specific labels that match the destination and user vocabulary.
- Preserve conventions unless a measured benefit justifies making users learn a new interaction.
- Build a clear visual and content hierarchy so users can scan headings, choices, status, and next actions without reading every word.
- Remove competing calls to action and decorative emphasis that obscures the primary task.
- Disclose detail progressively when showing everything at once would hinder the current decision, while keeping important constraints visible before commitment.
- Keep destructive, irreversible, expensive, or privacy-sensitive consequences explicit before the user acts.
