# Mobile interaction

- Assume interruption, one-handed use, changing connectivity, glare, motion, limited attention, and a software keyboard that reduces available space.
- Keep primary actions reachable and targets large enough for imprecise touch without creating accidental activation.
- Do not make an undiscoverable gesture the only way to perform an essential action. Provide a visible equivalent.
- Respect platform navigation, back behavior, safe areas, text scaling, permissions, and input conventions unless the product has strong evidence for an exception.
- Use sensors and device capabilities only when they reduce user effort and have a clear permission explanation, fallback, and failure path.
- Save progress early and often. Mobile context makes interruption ordinary rather than exceptional.
