# Automated testing design

Use this reference when designing, writing, refactoring, or reviewing automated tests in any language.
Treat a unit as a coherent behavior or unit of work, not automatically one method or class.
Choose the smallest test boundary that gives trustworthy evidence without replacing important integrations with assumptions.
