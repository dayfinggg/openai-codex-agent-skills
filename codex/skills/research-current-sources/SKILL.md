# Research Current Sources

1. Define the exact claim, relevant date range, jurisdiction, product version, and required evidence. Treat any unresolved dimension as a stated research constraint.
2. Search primary sources first: official documentation, standards, laws, specifications, source repositories, papers, datasets, and first-party statements. Use secondary sources only to discover or independently corroborate primary evidence.
3. Verify publication and event dates, authorship, scope, version, and whether the source remains operative. Resolve material conflicts with another authoritative source or report the conflict.
4. Separate sourced facts from inference. Cite the page that directly supports each material claim and avoid citations that only mention the topic.
5. Return the answer requested, not a research diary. State material uncertainty, missing evidence, and the date through which the result is current.

Finish only when every material claim is cited or explicitly marked as an inference or unresolved.
