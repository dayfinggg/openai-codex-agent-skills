Read when inspecting Node.js or Python stacks, values, or execution timing can distinguish the current hypotheses.

1. Identify the interpreter actually serving the operation, its version, launch arguments, source maps where relevant, and the repository's test command. Choose a breakpoint at the first suspected contract violation and inspect inputs, outputs, caller, and exception state. Breakpoints alter scheduling, so verify timing-sensitive findings with the normal reproduction as well.

2. For Node.js, `node --inspect` enables the inspector and binds to loopback by default. `node inspect` provides an interactive CLI client. Use an available debugger session rather than launching an interactive prompt in a noninteractive shell. The inspector grants code execution. Do not expose it publicly or bind it to `0.0.0.0` for convenience. Attach only to the authorized process, and do not restart a live service merely to gain a debugger. Read the installed release's debugger documentation before using additional options.

3. For Python, `breakpoint()` or `python -m pdb` supports state inspection in an interactive session. Pdb can enter post-mortem debugging after an exception and automatically restarts the target afterward, so do not use it for side-effecting replays without controlling that lifecycle. Process attach with `-p` requires Python 3.14 or later and may wait until the process executes bytecode. Do not leave a shell blocked at a debugger prompt. Use bounded, targeted stack capture or instrumentation when no interactive session exists.

4. For performance, use a timing harness or profile under representative load instead of treating verbose logs or debugger timings as a baseline. Remove temporary breakpoints, debug flags, and probes, then rerun the normal caller path and relevant regression test.

Read the official [Node.js debugging and security guide](https://nodejs.org/en/learn/getting-started/debugging) and the [Node.js 24 debugger reference](https://nodejs.org/docs/latest-v24.x/api/debugger.html) for that branch. The general security guidance does not establish new options for other major versions. Python documents [pdb for 3.15](https://docs.python.org/3.15/library/pdb.html), including version-added attach support. Retrieve the installed major/minor's documentation when it differs.
