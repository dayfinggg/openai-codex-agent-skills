# Codex Agents and Skills

[English](README.md) · Українська · [Русский](README.ru.md)

Знімок локального налаштування Codex автора на **2026-10-15**, який містить **18 інженерних навичок, 12 спеціалізованих агентів**, спільну інструкцію та переносиму конфігурацію.

Навички охоплюють код, безпеку, тестування, документацію, архітектуру, HTTP API, бази даних, інтерфейси, 3D, спостережуваність, стійкість сервісів, залежності, випуск ПЗ та безпеку LLM. Агенти призначені для дослідження, діагностики, реалізації та перевірки.

Це особиста конфігурація, а не офіційний продукт OpenAI. Системні навички, навички плагінів, ключі, історія чатів, кеші, локальні шляхи та налаштування застосунку не публікуються.

## Встановлення та заміна старої версії

Завантажте й розпакуйте [ZIP-архів](https://github.com/dayfinggg/openai-codex-agent-skills/archive/refs/heads/main.zip) або клонуйте репозиторій:

```sh
git clone https://github.com/dayfinggg/openai-codex-agent-skills.git
cd openai-codex-agent-skills
```

Із розпакованої або клонованої папки запустіть інсталятор. Він використовує включені файли без повторного завантаження.

### Windows

Потрібен Windows PowerShell 5.1 або PowerShell 7.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

### macOS і Linux

Потрібна POSIX-сумісна оболонка й утиліта SHA-256, наприклад `sha256sum`, `shasum` або `openssl`.

```sh
sh scripts/install.sh
```

Перезапустіть Codex після встановлення.

**За замовчуванням виконується повна заміна.** Інсталятор створює резервну копію, замінює спільну інструкцію, усі несистемні навички й користувацьких агентів, видаляючи старий набір. Системні навички `skills/.system`, плагіни, авторизація, чати й сторонні файли зберігаються. Наявні значення конфігурації не замінюються, відсутні параметри додаються, а `model_instructions_file` підключає нову інструкцію.

Для нової конфігурації використовуються `gpt-6.1-sol` із мисленням `medium` і модель субагентів `gpt-6-luna` із мисленням `max`. **Також увімкнено `approval_policy = "never"` і `sandbox_mode = "danger-full-access"`.** Перед встановленням перевірте [конфігурацію](codex/config.toml), якщо вам не підходять такі права доступу.

## Оновлення

Щоб завантажити й встановити актуальну версію з GitHub без оновлення робочої копії:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\update.ps1
```

```sh
sh scripts/update.sh
```

Потрібен інтернет, для оболонки додатково потрібні `curl` і `tar`. Оновлення зберігає вибраний режим встановлення. Для Git-клону можна натомість виконати `git pull --ff-only` і повторно запустити інсталятор.

Інструкції, навички й агенти перенесені з локального налаштування без переписування вмісту. З конфігурації експортовані лише переносимі параметри. Старі навички, імпортовані інструменти skill-creator та застарілі дослідницькі документи видалені.

Параметр `model_instructions_file` замінює вбудовані інструкції моделі, а не лише додає правила проєкту. Див. [офіційну документацію OpenAI](https://learn.chatgpt.com/docs/config-file/config-reference) та [опис користувацьких агентів](https://learn.chatgpt.com/docs/agent-configuration/subagents). Інсталятор зберігає використовувану автором структуру `$CODEX_HOME/skills`, хоча [актуальна документація навичок](https://learn.chatgpt.com/docs/build-skills) описує `$HOME/.agents/skills` для користувацького набору.

## Перевірка інсталяторів

Потрібен Python 3.11 або новіший:

```sh
python -m unittest discover -s tests -v
```

Тести працюють у тимчасових папках і не зачіпають справжнє налаштування Codex. Відсутні оболонки позначаються як пропущені перевірки.
